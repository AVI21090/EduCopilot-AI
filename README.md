# 🎓 EduCopilot AI

An AI-powered study assistant built using LangChain, Google Gemini, ChromaDB, and Streamlit.

## 🚀 Features

- AI Chatbot
- PDF Chat (RAG)
- Multi PDF Support
- Chat Memory
- Notes Summarizer
- Quiz Generator
- Flashcards
- Study Roadmap Generator
- Resume Analyzer
- Tool Calling
- AI Agent
- Authentication
- Deployment

## 🛠️ Tech Stack

- Python
- Streamlit
- LangChain
- Google Gemini
- ChromaDB
- PyPDF
- Python Dotenv
